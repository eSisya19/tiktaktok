# Sika Wiki

Official product information for **Sika**, a WhatsApp marketing and automation tool for small businesses in Zambia, developed by Cryon Technologies Limited.

## GitHub Pages

This repository contains a static website and an automatic GitHub Pages deployment workflow.

To publish it:

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Open the **Actions** tab and run **Deploy Sika Wiki to GitHub Pages** if it does not start automatically.

## Custom domain

In **Settings → Pages → Custom domain**, enter your chosen domain. For `wiki.sika.cryon-tech.com`, add a DNS CNAME record pointing `wiki.sika` to `esisya19.github.io`, then enable **Enforce HTTPS** after GitHub verifies it.
